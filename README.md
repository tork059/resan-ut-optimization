# Оптимизация регламентных заданий 1С:УТ

Проектный документ по снижению нагрузки регламентных и фоновых заданий на рабочую базу
1С:Управление торговлей в рабочие часы.

**Открыть документ:** https://tork059.github.io/resan-ut-optimization/

Текущая волна — **В1: освобождение окна 15:00–21:00** под новое регламентное задание.
Основание — аудит регламентных и фоновых заданий v3 (журнал за 16.08–16.09.2026,
выгрузка расписаний всех 98 заданий от 21.09.2026).

## Что внутри

Документ — одна страница `index.html` без зависимостей и сборки. Разделы:

| № | Раздел | Назначение |
|---|--------|-----------|
| 01 | Табло | ключевые цифры окна: сколько занято сейчас, сколько останется, что высвобождается |
| 02 | Карта суток | 24 часа × задания, машинное время в каждом часе; переключатель «сейчас / после волны 1» |
| 03 | Целевая раскладка | как собираются сутки после волны 1; что правится расписанием, что требует кода |
| 04 | Реестр заданий | расписание сейчас → целевое, вклад в окно, привязка к задаче; фильтры |
| 05 | Волны и задачи | пять волн, задачи с подзадачами, дедлайнами, критериями приёмки и зависимостями |
| 06 | Блокеры | открытые вопросы с указанием, какие задачи они держат |
| 07 | Замеры | план/факт по метрикам; волна не закрывается без замера |
| 08 | Риски | что может вернуть нагрузку в окно |
| 09 | Решения | журнал принятых и предложенных решений |
| 10 | Версии | журнал изменений документа |

## Как вести проект

**Прогресс считается сам.** Отметить подзадачу выполненной — заменить `[ ]` на `[x]`
и добавить классу `li` значение `done`:

```html
<li class="done"><i>[x]</i>Текст подзадачи</li>
```

Проценты в шапке волны и ширина полосы прогресса пересчитываются при загрузке страницы.

**Карта суток считается из данных, а не рисуется.** Массив `JOBS` в конце `index.html`
задаёт для каждого задания два сценария — `now` и `aft`:

- `runs: [[стартовый час, длительность в часах], …]` — прогоны по расписанию;
- `cont: 0.204` — круглосуточное задание, часы машинного времени в каждом часе;
- `contWin` — то же значение внутри окна 15:00–21:00, если оно другое;
- `hours: {9:0.035, …}` — задание с почасовой сеткой внутри окна.

Цифры на табло (занято сейчас, останется, высвобождается, доля) берутся из этого же
массива — править их в тексте не нужно.

**Окно** задаётся константами `WIN_FROM` и `WIN_TO`. Для следующей волны достаточно
поменять их, чтобы карта и все суммы пересчитались под другой интервал.

## Порядок обновления

1. Внести правки в `index.html`.
2. Проставить дату в `<span class="upd">` у изменённых разделов.
3. Повысить версию в шапке (`Версия 0.1`) и добавить строку в раздел 10.
4. Коммит с заголовком `Проектный документ vX.Y` — версия в коммите и в шапке совпадают.

Публикация — GitHub Pages из ветки `main`, корень репозитория. Файл `.nojekyll`
отключает обработку Jekyll.
